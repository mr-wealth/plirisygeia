# Como fazer clonagem completo
Quando queira fazer a clonagem do repositório principal, a pasta do submódulo estará vazia por padrão. Você precisarão executar este comando para obter os arquivos do submódulo (3.Implementacao):

```git submodule update --init --recursive

Alternativamente, pode simplesmente clonar o projeto principal usando 

```git clone --recurse-submodules https://github.com/mr-wealth/plirisygeia.git

para baixar tudo de uma vez.
